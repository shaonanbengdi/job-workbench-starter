# 🎯 求职工作台

一个跑在本地电脑上的求职管理工具：把经历、岗位、投递、日程放在一处，投不同岗位时快速组合出对应简历，再配一个 Chrome 插件把招聘网站上看到的岗位一键存进来。

**不用注册、不用装数据库、不连服务器。** 只需要 Python 3，双击就能用，数据全在你自己的 `data.db` 里。

> 这是分发的示例版本，库里的人物、企业、岗位、投递记录都是虚构的（星驰汽车、远航动力等企业并不存在），
> 打开就能看到每个页面长什么样，然后把内容换成你自己的。

## 功能一览

- **经历卡片库** —— 每段经历一张卡，简历版和故事版分开写，投递时按岗位挑
- **岗位管理** —— 按企业分组、按重要程度分级、拖拽排序、规则标签限制投递数量
- **简历生成** —— 选中岗位后自动匹配相关经历，实时预览，导出 PDF / Markdown
- **投递看板** —— 七段状态流转，拖拽改状态，一眼看出卡在哪一步
- **日历提醒** —— 截止日期、笔试、面试混在一张月历上，提前 N 天提醒
- **招聘信息** —— 候选池，把外部抓来的岗位先存着，标记「纳入」再进正式岗位库
- **校招导航** —— 企业校招入口速查（可选数据）
- **浏览器插件** —— 招聘网站上按一下快捷键，岗位连同 JD 直接存成卡片

## 快速开始

```bash
git clone https://github.com/shaonanbengdi/job-workbench-starter.git
cd job-workbench-starter
python server.py
```

浏览器会自动打开 `http://127.0.0.1:8765`。没有自动打开就手动访问。

- **Windows**：也可以直接双击 `启动工作台.bat`
- **macOS / Linux**：`./start.sh`
- 不需要 `pip install`，只用 Python 标准库

端口被占用时换个端口：`python server.py --port 8766`（换到 8765~8784 之间，插件会自动找到）

### 不想装 Python 的话

用便携版：解压后双击 `求职工作台.exe`，不需要 Python，数据存在 exe 旁边的 `data.db`，整个文件夹拷到 U 盘就能带走。

浏览器插件也在这个文件夹里的 `浏览器插件` 子目录，按上面的安装步骤加载一次即可。

便携版由 `packaging/build.py` 生成（需要先 `pip install pyinstaller`）：

```bash
python packaging/build.py          # 产出 dist/求职工作台/ 和 zip
```

打出来的目录长这样：

```
求职工作台/
├── 求职工作台.exe      # 双击启动
├── data.db            # 首次运行自动生成
├── backup/            # 自动备份
├── 使用说明.txt
├── 浏览器插件/          # 扩展，加载一次即可
└── _internal/         # Python 运行时与程序资源，别动
```

## 功能详解

### 1. 仪表盘

打开就是今天该干什么：待投递岗位数、本周笔试面试、7 天内到期的截止日期，以及投递漏斗（总投、已回复、面试中、Offer）。

### 2. 经历卡片库

整个系统的底料。每段经历做成一张卡，一张卡可以复用到任意多份简历。

**每张卡写两版：**

- **简历版** —— 3~5 行，进简历。写动作 + 方法 + 量化结果，例如「优化尾部造型三轮，整车风阻系数降低 0.012（约 4%）」
- **故事版** —— 自己看、面试用。写清背景、你负责哪块、遇到什么问题怎么解决、导师或评委关心什么

分成两版是因为这两件事的目标不同：简历要短要有数字，面试要能展开讲清楚你的判断过程。

### 3. 岗位管理

- **新增岗位**：填企业名、岗位名；粘上招聘链接点「自动填充」会把网页标题和正文抓回来（普通网页有效，前端渲染的站点抓不到，那种情况用插件或直接粘贴）
- **重要程度**：重点关注 / 可投 / 暂缓 / 跳过，四级
- **按企业分组**：自动归组，点企业名折叠。企业名旁显示标签和该企业已投数量
- **拖拽排序**：拖企业组调顺序，拖岗位卡在企业内调顺序；每行还有「置顶」把整个企业提到最前
- **规则标签**：在「标签管理」里建规则标签（如「最多投递 3 个」），打在任一岗位上，该企业就受这个上限约束，超了会提醒

### 4. 简历生成

四步：选目标岗位 → 系统按 JD 关键词匹配经历卡并给出匹配度 → 你勾选调整 → 实时预览导出。

匹配只是给建议，最终用哪几段由你定。

### 5. 投递计划

状态流转：**计划投递 → 已投递 → 测评 → 面试 → 感谢信 / Offer / 结束**

- **看板视图**：卡片在列间拖拽改状态，每列显示数量
- **表格视图**：一行一条，完整列出计划日期、实际投递日期、当前状态、最近更新
- 从岗位详情点「加入投递计划」，或手动添加

### 6. 日历

月视图看整月，点某天新建事件。支持截止日期 / 笔试 / 面试 / 跟进提醒 / 岗位提醒五类，可关联到具体岗位，可设提前 N 天或 N 小时提醒。同一天同一时段撞车会标注「同时开」。

### 7. 招聘信息

候选池，放还不想直接进岗位库的岗位。

- **三种来源**：手动粘贴 JSON 数组、插件抓取、从「校招导航」一键加入
- **筛选**：状态、类型、企业、城市、学历、来源、匹配度，加关键词搜索
- **处理**：「纳入」生成岗位卡（可勾选同时建投递计划、建日程），「排除」归档，也可重置回待处理
- **高校就业平台抓取**（可选）：默认关闭，接自己学校的 91job 站点时在 `server.py` 顶部填 `SITE_CODE`、`SCRAPER_BASE` 等，并把 `CATEGORIES` 里要用的栏目 `enabled` 改成 `True`；抓回来的条目按 `TARGET_COMPANIES` 里的企业关键字判断是否对口

### 8. 用户画像

填一次，多处复用：学历、研究方向、目标岗位、目标城市、薪资预期、技术栈、目标企业、规避项。插件的「筛岗位」就是按这份画像判断的。

### 9. 校招导航（需自备数据）

企业校招入口速查页，数据文件是与 `server.py` 同目录的 `campus_nav.json`。

**本版本不带这个文件**，页面会提示去确认文件位置。自己整理一份放进去，格式：

```json
{
  "meta": { "title": "2027 届校招导航", "updated": "2026-10-01" },
  "rows": [
    {
      "id": "campus2027_example",
      "企业": "星驰汽车",
      "类别": "自主整车",
      "性质": "民企",
      "主要基地": "上海、合肥",
      "校招入口": "https://jobs.example.com/campus",
      "链接状态": "",
      "对口方向": "热管理/气动CFD/结构CAE",
      "优先级": "S",
      "备注": "",
      "来源": "",
      "其他投递渠道": ""
    }
  ]
}
```

- 支持按企业关键字 / 城市 / 方向搜索，按类别 / 优先级 / 对口方向筛选
- 「加入候选池」把该企业导入「招聘信息」，重复点击不会产生重复条目

### 10. 宣讲会日程（需自备数据）

把宣讲会按日期排成一张表，标出档位（S 必去 / A 建议 / B 可选）、
时间地点、HR 联系方式、与本校岗位的对口说明。

- 同一时段撞场的场次会标出来，避免两头跑
- 可只看最近将要开始的场次，或按档位、关键字筛选
- 其他学校办的场次单独列一栏（`talks.json` 里的 `cross` 字段）

数据文件 `talks.json` 与 `server.py` 同目录，最简格式：

```json
{ "rows": [ { "日期": "2026-11-10", "时间": "19:00", "企业": "某某公司",
              "地点": "报告厅", "档位": "S", "对口说明": "热管理岗" } ] }
```

### 11. 往届就业

学长学姐的毕业去向，用来看哪家真的在招人。默认带一份虚构示例（8 家企业），
把 `index.html` 里的 `EMP_DATA` 换成你所在学院的就业质量报告数据即可。

- 每家企业：总人数、分年度趋势、主要对口专业、秋招状态与优先级
- 点「关注」标记心仪企业，点「投递」自动建岗位卡和投递记录
- 可按 S 级、已开放秋招、已关注、已投递快速筛

## 浏览器插件「岗位速存」

在招聘网站上把当前页的岗位存成工作台里的卡片，省掉复制粘贴。

### 安装

1. 先启动工作台（`python server.py` 或双击 `启动工作台.bat`），没启动插件存不进去
2. 浏览器打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
3. 打开右上角 **开发者模式**
4. 点 **加载已解压的扩展程序**，选本目录下的 `浏览器插件` 文件夹（里面有 `manifest.json` 的那一层）

### 用法

装好后每个网页右侧会出现两个按钮（可拖到任意位置，位置会记住），上下顺序会跟着你上次用的动作调整：

- **存岗位** —— 详情页用。抓岗位名、公司、薪资、地点、学历经验、部门、招聘人数、截止日期、JD 全文、投递链接，存进岗位库
- **筛岗位** —— 列表页用。读你的用户画像，从这一页里挑出方向和条件对得上的岗位

快捷键 `Alt+Shift+J` 存岗位、`Alt+Shift+F` 筛岗位；也可以右键菜单操作，或用工具栏图标。

存之前会有一张**实时预览卡**，字段能逐项改，确认后再入库。

### 已适配站点

北森 iTalent、51job wecruit、HCM Cloud、飞书招聘、91job 智慧就业平台、BOSS 直聘、智联招聘、猎聘、拉勾，以及腾讯文档 / WPS / 飞书的在线表格。

其余任意招聘页走通用识别，不保证字段全，但基本能捞出岗位名、公司和正文。

## 自动识别配置

插件靠大模型读页面内容来填字段，**不配置就用不了**，这是唯一的硬性依赖。

配置入口：插件面板里的 **识别设置**（右键菜单也能进）。

| 项 | 怎么填 |
|---|---|
| 平台 | 智谱 GLM / 通义千问 / Kimi / DeepSeek / OpenAI 兼容 / 本地 Ollama / 自定义，选一个 |
| API Key | 你的密钥，存到本机工作台，不进浏览器扩展 |
| 模型 | 可留空，留空用该平台默认模型 |
| 接口地址 | 可留空，留空用该平台默认地址 |

几点实际经验：

- 选具体厂商（如「DeepSeek」）时模型和地址都能留空，自动用该厂商的默认值
- 选「OpenAI 兼容」默认指向 `api.openai.com`；如果要借它连别家（很多人这么用 DeepSeek），得自己改接口地址，**且必须带完整路径**（`https://api.deepseek.com/chat/completions`，少了结尾那段就通不了）
- 选「自定义」两项都没有默认值，全靠自己填
- 本地 Ollama 免费、不联网，代价是慢
- 填完先点「测试连接」，返回成功再去抓岗位，省得抓半天才发现 Key 错了

每次抓取需要 5~20 秒，因为要把整页内容交给模型读一遍。

## 招聘监控推送（附带的小工具）

工作台是你主动往里存岗位；`招聘监控推送` 目录里是另一件事 ——
让机器**定时盯着学校就业网**，有新的岗位/宣讲会就筛选后推到你手机上。

它是独立的 Python 脚本，和工作台互不干扰，用不用都行。

**怎么用**：把 `招聘监控推送` 文件夹单独拖进 WorkBuddy，说一句「帮我配置这个招聘监控」，
它会带着你一步步填配置（学校网址、栏目 ID、企业微信机器人）。也可以双击里面的
`4_引导配置.bat` 自己配。

> 这个目录里的站点参数和企业微信地址在分发时已被清空 —— 那些是原作者的私人信息。
> 拿到手需要填三项：学校就业网域名与代码、四个栏目的 ID、企业微信机器人地址。
> 详细步骤和怎么配定时任务，见 `招聘监控推送/README.md`。

配好后的效果：每天定时跑一次，把符合你方向的岗位、宣讲会推送到企业微信群，
同时在 `reports/` 生成一份 Markdown 日报。

## 数据与隐私

- 所有数据在本地 `data.db`（SQLite），不上传任何服务器
- 每天自动备份到 `backup/`，也可手动创建和恢复，或导出成 JSON
- API Key 存在本机 `data.db` 的 `meta` 表，界面上回显时打码
- 插件不存任何凭据，也没有访问外网的权限，只能连本机地址；识别请求都由本机工作台转发出去
- 唯一的外网请求是发给你自己配置的模型服务商

## 示例数据

`data.db` 里是虚构数据：人物「陈晨」，企业「星驰汽车 / 远航动力 / 宏途智能 / 云淞精工 / 蓝湾研究院」等，岗位 JD、投递记录、经历卡片都是编的。

**一键清空**：仪表盘右下角「数据管理」里有「清空示例」，
只删标记为示例的条目，你自己后来录的一条不动 —— 可以先放心往里加东西再清。

想换行业（示例是按车辆工程 / CFD / 热管理编的），改 `tools/make_demo_db.py` 顶部的常量，
然后 `python tools/make_demo_db.py --force` 重新生成一份。

想彻底从零开始，删掉 `data.db` 重启会重新建库，但页面还会自动灌入一小份内置示例（3 张经历卡、2 个岗位），用「清空示例」清掉即可。

## 常见问题

**启动报端口被占用？**
`python server.py --port 8766` 换个端口。插件会自动从 8765 起往后找，只要落在 8765~8784 之间就不用手工配。

**插件显示「未检测到工作台」？**
先确认工作台在跑（浏览器能打开 `http://127.0.0.1:8765`），再确认加载的是 `浏览器插件` 这个文件夹本身。

**自动识别一直失败？**
到「识别设置」核对四项：服务商、模型名、接口地址、API Key。地址要带完整路径。点「测试连接」通了再抓。

**抓来的 JD 里混着导航和推荐岗位？**
换个页面重新抓，或者直接在预览卡里手工删。列表型门户页容易把侧栏推荐一起带进来，详情页通常干净得多。

**连着存好几张卡，前面的不见了？**
工作台页面开着且数据较旧时，它下一次保存会把新卡覆盖掉。**存多张卡之前先在工作台按 F5 刷新一次。**

**数据存哪、怎么备份？**
`data.db` 是全部数据，`backup/` 里是每日自动备份。要迁移就把 `data.db` 拷过去，要恢复就把备份文件改名成 `data.db` 放回来。

## 目录结构

```
├── server.py              # 后端：本地 HTTP 服务 + SQLite
├── index.html             # 前端：单文件，无构建步骤

│   ├── lib/job-parser.js  # 各站点适配

```
